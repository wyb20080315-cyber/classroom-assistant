# 🎓 课堂助手 Classroom Assistant

纯前端课堂辅助网站：英语课程录音 → 实时中文翻译字幕 → AI 课后分析。无需后端，部署到任意静态托管平台即可使用。

---

## 📋 功能介绍

### 1. 录音功能
- 点击红色大圆按钮开始录音，再次点击停止。
- 录音停止后，录音文件会出现在"录音列表"中，支持多条临时存放。
- 点击"⬇ 下载"可以将录音保存为 MP4 文件到本地电脑。
- 点击"✕ 删除"可以移除不需要的录音。

### 2. 实时翻译
- 录音时，页面下方会实时显示中文翻译字幕。
- 默认使用免费翻译接口（MyMemory）。
- 如果在设置中开启了"使用自定义模型进行实时翻译"，则会使用你配置的大模型进行翻译（效果更佳但会消耗 API 额度）。

### 3. AI 课后分析
- 停止录音后，可以选择电脑中的 TXT 文本文件进行 AI 分析。
- AI 会自动生成课程总结、关键术语列表、难点解析和学习建议。
- 分析结果可以直接复制。

### 4. 设置功能
- 点击右上角的 ⚙️ 齿轮图标可以随时修改 API 配置。
- 首次打开网站时会弹出设置面板，你可以点击左上角的 ✕ 号跳过设置（但将无法使用翻译和分析功能）。

## 📘 使用说明

### 一、首次打开网站

首次打开网站时，会自动弹出设置面板，需要填写以下三项：

| 字段 | 说明 | 在哪里获取 |
|------|------|-----------|
| **API Base URL** | 大模型接口的地址 | 登录你的 API 服务商后台，找到 API 文档中的 Base URL，通常是 `https://xxx/v1` 格式 |
| **API Key** | 调用 API 的密钥 | 在 API 服务商后台的 "API Keys" 页面创建并复制 |
| **Model 名称** | 模型的名字 | 在 API 服务商文档中查看，常见值：`deepseek-chat`、`gpt-4o-mini`、`qwen-plus` 等 |

**常用 API 服务商参考：**

| 服务商 | Base URL 示例 |
|--------|--------------|
| OpenAI 官方 | `https://api.openai.com/v1` |
| DeepSeek | `https://api.deepseek.com/v1` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |

填写完成后点击 **"保存并开始使用"**，设置会自动保存在你的浏览器本地。

### 二、主界面功能

进入主界面后，你会看到以下功能区：

| 功能区 | 操作 |
|--------|------|
| **🎤 开始/停止录音** | 点击红色大圆按钮开始录音，再点一次停止。录音时会有计时器 |
| **📂 录音列表** | 录音停止后出现，显示所有录音文件，支持下载和删除 |
| **📝 实时翻译** | 录音时实时显示中文翻译字幕 |
| **🔍 AI 课后分析** | 上传 TXT 文本文件，点击"开始分析"获取 AI 总结 |
| **📊 分析结果** | AI 返回的课程总结、术语表、难点解析等 |
| **⚙️ 齿轮图标** | 随时修改 API 配置 |

### 三、使用流程

1. **录音**：把设备放在课堂前方，点击"开始录音"，页面下方会实时显示中文翻译字幕。
2. **停止**：课程结束后点击"停止录音"，录音文件会自动出现在列表中，点击下载可以保存到本地。
3. **分析**：将录音转成的 TXT 文本上传，点击"开始分析"，AI 会自动生成课程总结。
4. **复制**：点击分析结果旁的"复制"按钮，可将分析结果保存到备忘录或笔记软件中。

### 四、隐私说明

**所有 API 密钥仅保存在你的浏览器本地（localStorage），不会上传到任何服务器。** 更换浏览器或清除浏览器数据后需要重新配置。

## ❓ 常见问题

### Q：浏览器不支持语音识别怎么办？
A：请使用 **Google Chrome** 浏览器（桌面版或 Android 版）。Safari 和 Firefox 对 Web Speech API 支持不完整。

### Q：API 调用失败怎么办？
A：
1. 点击 ⚙️ 设置，检查 API Base URL 是否以 `/v1` 结尾。
2. 检查 API Key 是否正确复制，不要有多余空格。
3. 检查 Model 名称是否与该 API 支持的模型一致。
4. 如果提示 CORS 错误，说明你的中转站未开启跨域支持，请联系中转站管理员或使用支持跨域的接口。

### Q：免费翻译效果不好怎么办？
A：在设置中开启 **"使用自定义模型进行实时翻译"**，会使用你配置的大模型进行翻译，效果更佳但会消耗 API 额度。

### Q：录音文件怎么播放？
A：下载的 `.mp4` 文件可以用 Chrome、Edge 浏览器直接打开播放，也可用 VLC 播放器播放。

### Q：AI 分析支持哪些文件格式？
A：目前仅支持 **TXT 文本文件**。如果你录的是音频，需要先使用其他工具将音频转换为文本，然后再上传进行分析。

## 🛠 技术说明

- **技术栈**：纯 HTML + CSS + JavaScript，无任何后端依赖
- **录音**：浏览器 MediaRecorder API
- **语音识别**：浏览器 Web Speech API（推荐 Chrome）
- **翻译**：默认使用 MyMemory 免费 API，也可使用自定义大模型
- **分析**：调用用户配置的 OpenAI 兼容 API（Chat Completions 格式）
- **部署**：任何静态文件托管平台（Vercel、Netlify、GitHub Pages 等）
